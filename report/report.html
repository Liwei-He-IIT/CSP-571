I’m using the UCI Secondary Mushroom Dataset to predict whether a simulated mushroom record is edible or poisonous.

I built and compared three models: logistic regression, a decision tree, and a random forest.

3. Exploratory Data Analysis

Class distribution

eda_plots$class_distribution

The classes are close to balanced - 44.6% edible, 55.4% poisonous - so accuracy is a reasonable metric here. I also track poisonous-class recall, since calling a poisonous mushroom “edible” is the costlier mistake.

Missing values

eda_plots$missing_values

A handful of variables are missing more than 80% of their values, which ruled out dropping incomplete rows. I kept them and coded missing entries as their own unknown level - if missingness itself correlates with edibility, the model can use that signal instead of losing it.

Numerical predictors

eda_plots$numeric_boxplots

Edible mushrooms tend to run a bit larger - bigger cap diameter, taller and wider stems, though all three measurements have long right tails. I left those outliers in; they’re part of the simulated data as generated.

Selected categorical predictors

eda_plots$categorical_class_proportions

I selected cap_shape, gill_attachment, and habitat for this plot - together they cover cap morphology, gill structure, and growing environment, and their levels show visibly different class proportions. A few habitat categories are entirely one class, but those are also the smallest groups. Most common levels still contain a mix of both classes, which is the point of combining several predictors in a model.

Correlation check for numerical size predictors
Comparison Pearson Spearman
stem_width vs. cap_diameter 0.695 0.863
stem_width vs. stem_height 0.433 0.498

cap_surface, gill_attachment, cap_color, and gill_color top the random forest’s permutation-importance ranking. stem_width - the first split in the simplified tree - ranks around 11th. That’s not a contradiction: a single tree picks the locally best one-step split, while permutation importance measures the accuracy drop from shuffling a variable across the whole forest. The correlation check shows why: stem_width overlaps heavily with cap_diameter (r = 0.695, Spearman = 0.863), more than with stem_height. Once cap_diameter is available, shuffling stem_width doesn’t cost the forest much - it can recover similar information elsewhere. The ranking reflects each variable’s marginal contribution within this forest, not a causal claim about what makes a mushroom poisonous.

Random forest wins outright - perfect metrics, zero dangerous false negatives. The decision tree is close behind at 98.91% accuracy and has one real advantage: you can explain the rule to someone. Logistic regression trails both by a wide margin, which suggests the edible/poisonous boundary here isn’t linear. There’s enough interaction between stem dimensions, color and surface texture, that a straight-line model can’t capture it.

I will go with the random forest: the cost of a false negative is too high to trade away for interpretability. The decision tree as the easy-to-explain version, since a 1-2% accuracy gap is okay for something you can actually walk someone through.

One caveat on the perfect random forest score: all 61,069 records come from the same simulation process built on only 173 real species, so a random train/test split isn’t really testing on an unseen species - it’s closer to testing on a held-out sample from the same distribution. A species-aware split would be a tougher, more realistic test. I didn’t have time to build that here, but it’s the first thing I’d try next, along with checking how much accuracy holds up using just the top 3-4 features.
